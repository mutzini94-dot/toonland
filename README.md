# 투네랜드 (TooneLand) 목업

투네이션 강냉이로 즐기는 온라인 가챠샵 컨셉의 단일 HTML 목업이에요. `index.html`을 브라우저로 열면 바로 동작해요.

## 들어 있는 것
- **가챠샵**: 입장료가 다른 여러 가챠 머신, 1~5성 캡슐, 머신이 커지며 공이 나오는 연출
- **뽑기판**: 칸을 골라 스크래치 복권처럼 긁는 뽑기판
- **크리에이터 퍼즐**: 즐겨찾기한 크리에이터 10명의 직소퍼즐(6조각)을 모아 완성하면 상품 + 크리에이터 응원 보너스, 퍼즐 오른쪽 실시간 완성 순위
- **팝콘 농장**: 씨앗을 심고 시간이 지나 수확하면 공개 확률표로 보상 결정
- **조각 교환소**, 명예의 전당(머신별 TOP 10), 실시간 당첨 피드
- **관리자 페이지(#admin)**: 예산·목표 RTP, 머신별 상품·확률 편집, 교환소·농장 관리, 퍼즐 순위 구간별 베네핏 설정과 마감된 달 수동 지급·지급 기록

## 참고
- 잔액, 당첨 피드, 순위, 다른 이용자 기록 등은 모두 예시 데이터예요. 진행 상황은 브라우저 localStorage에만 저장돼요.
- 공유 저장소(claude.ai 아티팩트 db)를 쓸 수 없는 환경에서는 관리자 설정도 이 브라우저에만 저장돼요.
- 크리에이터 이름은 예시 이름이에요.
